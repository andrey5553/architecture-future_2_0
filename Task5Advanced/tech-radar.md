# Целевой технологический стек и расширенный технический радар

### Радар включает:

- 4 квадранта: Languages & Frameworks, Tools, Platforms, Methods;
- 4 кольца: Adopt, Trial, Assess, Hold;

### Каждая технология/паттерн имеет:
- Статус;
- Обоснование;
- Рекомендации по применению.

# Технический радар (расширенный)

## Квадрант 1: Languages & Frameworks
(Языки программирования и фреймворки)

| Технология | Статус | Обоснование                                                                          |
| ---------- | ------ | ------------------------------------------------------------------------------------ |
| Python     | Adopt  | Основной язык для ИИ/ML, обработки данных, скриптов. Поддержка в Data Science и ETL. |
| Go         | Adopt  | Высокопроизводительные микросервисы, CLI-утилиты, backend. Используется в финтехе.   |
| С#         | Trial  | Поддерживается в легаси-сервисах. Новые проекты — только при необходимости.          |
| React      | Adopt  | Стандартный фронтенд для веб-интерфейсов, включая портал самообслуживания.           |
| TypeScript | Adopt  | Укрепляет надёжность фронтенда, используется с React.                                |

## Квадрант 2: Tools
(Инструменты разработки, мониторинга, интеграции)

| Технология                 | Статус | Обоснование                                                                 |
| -------------------------- | ------ | --------------------------------------------------------------------------- |
| Terraform                  | Adopt  | Основной инструмент IaC. Управляет облачной инфраструктурой в Yandex Cloud. |
| Kafka                      | Adopt  | Ядро событийной архитектуры. Заменяет Camel для асинхронной интеграции.     |
| Airflow                    | Trial  | Управление ETL/ELT-пайплайнами. Пилот в домене финансов.                    |
| Grafana + Prometheus       | Adopt  | Мониторинг и визуализация метрик в реальном времени.                        |
| Schema Registry            | Trial  | Управление схемами событий (Avro/JSON). Гарантирует совместимость.          |
| GitLab CI / GitHub Actions | Adopt  | CI/CD-платформа. Поддержка IaC, тестирования, развёртывания.                |

## Квадрант 3: Platforms
(Платформы, облачные и сервисные)

| Технология                  | Статус | Обоснование                                                                          |
| --------------------------- | ------ | ------------------------------------------------------------------------------------ |
| Yandex Cloud                | Adopt  | Основная облачная платформа. Поддерживает масштабирование, безопасность, compliance. |
| Kubernetes (Yandex Managed) | Trial  | Оркестрация микросервисов. Пилот в ИИ-домене.                                        |
| S3-совместимое хранилище    | Adopt  | Хранение сырых данных, медиа, резервных копий. Основа Data Lake.                     |
| PostgreSQL                  | Adopt  | Основная СУБД для транзакционных систем. Альтернатива SQL Server 2008.               |
| ClickHouse                  | Trial  | Аналитическая СУБД. Быстрая агрегация, подходит для near-real-time отчётов.          |
| DataHub                     | Trial  | Каталог данных. Основа Self-service BI и Data Mesh.                                  |

## Квадрант 4: Methods
(Архитектурные и организационные паттерны)

| Паттерн                      | Статус | Обоснование                                                                    |
| ---------------------------- | ------ | ------------------------------------------------------------------------------ |
| Event-Driven Architecture    | Adopt  | Ключевая архитектура. Повышает гибкость, скорость реакции, масштабируемость.   |
| Data Mesh                    | Trial  | Пилот в домене «Финансовые расчёты». Данные как продукт, доменные DPO.         |
| Self-service BI              | Trial  | Портал для аналитиков. Снижает нагрузку на DWH-инженеров.                      |
| Domain-Driven Design (DDD)   | Adopt  | Определение границ доменов, проектирование микросервисов и событий.            |
| Infrastructure as Code (IaC) | Adopt  | Terraform + CI/CD. Обеспечивает воспроизводимость и безопасность.              |
| Microservices                | Adopt  | Декомпозиция монолитов. Поддерживает независимые команды и релизы.             |
| Data Lakehouse               | Assess | Оценка Apache Iceberg + S3 + Spark. Потенциальная замена DWH.                  |
| Apache Camel                 | Hold   | Поддерживается как «мост» в миграции. Новые интеграции — только через события. |
| SQL Server 2008              | Hold   | Легаси. Постепенный вывод из эксплуатации.                                     |

## Ключевые решения и логика статусов
| Статус | Что означает                                    | Примеры                         |
| ------ | ----------------------------------------------- | ------------------------------- |
| Adopt  | Широко используется, рекомендуется к применению | Python, Terraform, React, Kafka |
| Trial  | Пилотируется в одном домене, готов к расширению | Data Mesh, DataHub, Kubernetes  |
| Assess | Изучается, нет пилота, но есть потенциал        | Data Lakehouse, Spark           |
| Hold   | Не используется в новых проектах, выводится     | SQL Server 2008, Camel          |

# Заключение: Преимущества целевого стека
| Цель                    | Решение                                                               |
| ----------------------- | --------------------------------------------------------------------- |
| Самообслуживание данных | DataHub + Self-service BI → аналитики строят отчёты без DWH-инженеров |
| Масштабируемость        | Облако + Kubernetes + Kafka → легко растёт с бизнесом                 |
| Гибкость интеграций     | Event-Driven Architecture → домены независимы                         |
| Data Mesh               | Trial → позволяет доменам управлять своими данными как продуктами     |
| Снижение техдолга       | Замена Camel и SQL Server 2008 → меньше легаси                        |
| Скорость реакции        | Kafka + ClickHouse → near-real-time аналитика                         |
