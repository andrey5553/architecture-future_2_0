# Карта рисков трансформации
| Риск                                           | Категория       | Вероятность | Влияние     | Описание                                                      |
| ---------------------------------------------- | --------------- | ----------- | ----------- | ------------------------------------------------------------- |
| Утечка персональных данных пациентов (ПДн)     | Архитектурный   | Высокая     | Критическое | Несанкционированный доступ к БД или утечка через API/фронтенд |
| Потеря состояния Terraform (tfstate)           | Технологический | Средняя     | Высокое     | Утрата tfstate → невозможность управления инфраструктурой     |
| Несанкционированное удаление ВМ или диска      | Технологический | Средняя     | Высокое     | Ошибка в CI/CD или злонамеренное действие → потеря среды      |
| Сбой медицинских устройств или задержка данных | Технологический | Средняя     | Критическое | Отказ IoT-шлюза или сети → потеря критических данных          |
| Недостаточная безопасность платёжных операций  | Архитектурный   | Средняя     | Высокое     | Нарушение PCI-DSS → штрафы, потеря доверия                    |
| Отсутствие MFA для врачей                      | Организационный | Высокая     | Высокое     | Учётные данные могут быть скомпрометированы                   |
| Зависимость от внешнего AI-провайдера          | Архитектурный   | Средняя     | Высокое     | Внешний сервис недоступен → задержка диагностики              |
| Низкая культура IaC в команде                  | Организационный | Высокая     | Среднее     | Ошибки в коде → сбои, откаты, долгие исправления              |
| Отсутствие резервного копирования БД           | Технологический | Низкая      | Критическое | Полная потеря данных при сбое                                 |
| Недостаточный аудит изменений                  | Организационный | Средняя     | Высокое     | Невозможно отследить, кто и что поменял                       |

# План управления рисками
| Риск                            | Мера по снижению                                                     | Тип меры                     | Ответственный     | Срок         |
| ------------------------------- | -------------------------------------------------------------------- | ---------------------------- | ----------------- | ------------ |
| Утечка ПДн                      | Шифрование БД (at rest + in transit), RBAC, аудит доступа            | Техническое                  | DevOps / Security | Сразу        |
| Потеря tfstate                  | Регулярный бэкап S3 + cross-region replication                       | Техническое                  | DevOps            | 1 неделя     |
| Несанкционированное удаление ВМ | Добавить prevent_destroy в ресурсы + проверка в CI                   | Техническое                  | DevOps            | Уже частично |
| Сбой медицинских устройств      | Резервный шлюз, мониторинг, буферизация данных                       | Техническое                  | Medical Team      | 2 недели     |
| Нарушение PCI-DSS               | Аудит платёжного шлюза, токенизация, внешний pentest                 | Техническое + Управленческое | Fintech Team      | 3 недели     |
| Отсутствие MFA для врачей       | Внедрить MFA в систему аутентификации (OAuth2 + TOTP)                | Техническое                  | Security          | 1 неделя     |
| Зависимость от внешнего AI      | Кэширование результатов, fallback-модель, SLA                        | Техническое                  | AI Team           | 2 недели     |
| Низкая культура IaC             | Обучение, code review, шаблоны, чек-листы                            | Управленческое               | Team Lead         | Постоянно    |
| Отсутствие бэкапа БД            | Настроить автоматическое резервное копирование + тест восстановления | Техническое                  | DevOps            | 1 неделя     |
| Недостаточный аудит             | Включить логирование CI/CD, доступа к БД, API                        | Техническое                  | DevOps / Admin    | 1 неделя     |

## Подробная классификация мер

### Технические решения (автоматизируемые)
| Риск           | Решение                                            |
| -------------- | -------------------------------------------------- |
| Потеря tfstate | S3 versioning + cross-region copy                  |
| Удаление ВМ    | lifecycle { prevent_destroy = true } + CI-проверка |
| Утечка данных  | Шифрование, RBAC, WAF, HTTPS                       |
| Сбой устройств | MQTT + буфер + мониторинг                          |
| Отсутствие MFA | Интеграция с Keycloak/Auth0 с поддержкой TOTP      |
| Нет бэкапа     | pg_dump + cron + offsite storage                   |

### Управленческие подходы (процессы, политики)
| Риск                | Решение                                       |
| ------------------- | --------------------------------------------- |
| Низкая культура IaC | Регулярные ревью, onboarding, чек-листы       |
| Нарушение PCI-DSS   | Назначить DPO, провести аудит, подписать SLA  |
| Недостаточный аудит | Политика журналирования, ежемесячные отчёты   |
| Зависимость от AI   | Договор с провайдером на SLA, пени за простой |

# Градация рисков (матрица)
| Влияние ↓ \ Вероятность → | Низкая | Средняя                           | Высокая                       |
| ------------------------- | ------ | --------------------------------- | ----------------------------- |
| Критическое               | —      | Утрата БД                         | Утечка ПДн                    |
| Высокое                   | —      | Зависимость от AI, Сбой устройств | Отсутствие MFA, Нарушение PCI |
| Среднее                   | —      | Потеря tfstate                    | Низкая культура IaC           |

## Приоритеты

### Критические 
- Утечка ПДн → шифрование + аудит
- Отсутствие MFA → внедрить за неделю
- Потеря tfstate / БД → настроить бэкап

### Высокие
- CI-проверка на delete
- Резервный IoT-шлюз
- Аудит платёжной системы

### Средние
- Обучение команды
- Code review
- Отчёты по безопасности
